How wrong parts are kept out
  • No matching by similar wording. Trying it proved the risk. It offered brake pads for "Brake pedal", tie rod ends for "Tie rod" and a timing belt for "Tensioner, timing belt": all different parts.
  • A part is only priced when NAPA says it fits this car, either in its exact-match answer or in its full catalogue with no version condition.
  • The one new automatic match is NAPA checked against NAPA: a catalogue part whose only condition is an engine code, priced only when that code is the car's own engine code from NAPA's exact-match answer.
  • A code mapping is only between codes for the same named part (brake fluid to brake fluid), and Gareth approves each one. Everything else is Gareth's price or Gareth's decision. Nothing is filled in by guesswork.
