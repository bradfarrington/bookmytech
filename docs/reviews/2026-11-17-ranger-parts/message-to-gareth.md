NAPA's live prices are now switched on, and I've been going through how well they cover our repairs. I used a 2024 Ford Ranger to test it, and there are gaps we need to close ourselves, so I need your steer on a few things.

The gaps fall into three groups:

We can fix this our side by matching each HaynesPro code to NAPA's code for the same part. You'd approve each match once, and it then works on every car.
• **NAPA doesn't sell the part at all.** Airbags, seat belts, speakers, seats and door panels: dealer or bodyshop work.
